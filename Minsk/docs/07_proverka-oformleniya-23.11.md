## 4. ЕСКД и ГОСТ — замечания и что сделано

> ЕСКД (ГОСТ 2.105, 2.316, 2.104) распространяется на конструкторские документы; статья конференции к ним не относится, поэтому рамка и основная надпись по ГОСТ 2.104 не требуются. Ниже — только те нормы ЕСКД и ГОСТ 7.32/7.0.100, которые применимы к текстовому научному документу.

### 4.1. ✅ Исправлено: курсив в подписи рисунка (файл 1)
Подпись «Рисунок 1 — Принципиальная электрическая схема…» была набрана курсивом. По ГОСТ 2.105 и ГОСТ 7.32 подпись под рисунком набирают без выделения, по центру. Курсив снят — оба файла оформлены одинаково.

### 4.2. ✅ Исправлено: добавлена ссылка на рисунок 1 (файл 2)
По ГОСТ 2.105 п. 4.3.1 и ГОСТ 7.32 на каждый рисунок должна быть ссылка в тексте до самого рисунка. В конце абзаца о LoRA-адаптации добавлено:
> Структура интеллектуального тьютора приведена на рисунке 1.

В файле 1 ссылка была изначально — «…приведена на рисунке 1» в абзаце «Основная часть».

### 4.3. ✅ Исправлено: расшифрованы сокращения (файл 2)
По ГОСТ 2.316 и ГОСТ 7.32 сокращения расшифровывают при первом упоминании. Добавлено:
- ИИ — «генеративного ИИ (искусственного интеллекта)»;
- API — «внешних API (программных интерфейсов)»;
- LoRA / QLoRA — «(низкоранговая адаптация)»;
- JSONL — «(построчный JSON; поля instruction, input, output)»;
- GPU — «(графическим процессором)»;
- LTS — «(долгосрочная поддержка)»;
- CUDA — «(платформа параллельных вычислений NVIDIA)»;
- PEFT — «(эффективная тонкая настройка)».

LLM было расшифровано ранее — «Большие языковые модели (LLM)».

### 4.4. ✅ Исправлено: листинг кода оформлен с подписью (файл 2)
Вместо абзацев без подписи:
- вводная фраза: «Фрагмент программы приведён в листинге 1: входные данные — текст лекции, выходные — структурированный конспект.» (ссылка на листинг до него);
- подпись по центру: «Листинг 1 — Фрагмент программы (класс IntelligentTutor, файл tutor.py)», TNR 10;
- код — TNR 9 пт, выравнивание по левому краю (без «растянутых» пробелов).

Так 9 пт относится к оформлению листинга, а не к основному тексту, и требование «TNR 10» для текста статьи не нарушается.

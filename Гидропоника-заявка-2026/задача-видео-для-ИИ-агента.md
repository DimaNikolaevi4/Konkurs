# Задание для ИИ-агента: нарезка видео стенда «Гидропоника» (удалённый агент)

> Агент не имеет доступа к локальным файлам, поэтому исходники и сдача результата идут
> через GitHub Releases репозитория Konkurs. Скачивание — публичное, без токена;
> для загрузки результата нужен токен — его выдаст Дмитрий в переписке (после сдачи работы токен отзывается).

## 2. Что нужно сделать

```
ЗАДАЧА: подготовить короткий видеофрагмент работы лабораторного стенда
«Гидропоника» для вставки в презентацию доклада на научной конференции.

1. Скачать исходники по ссылкам выше (начать с gotovyj.mp4).
2. Просмотреть и выбрать самый наглядный НЕПРЕРЫВНЫЙ фрагмент работы стенда:
   включение/работа насоса, подача или слив питательного раствора,
   срабатывание реле/индикации, поддержание уровня раствора в ёмкости.
3. Длительность фрагмента — строго 30–45 секунд.
4. Предпочтителен один фрагмент без монтажных склеек (точная обрезка начала
   и конца). Если непрерывный кусок не показателен — допускается склейка
   максимум из 2 фрагментов с плавным переходом.

ТРЕБОВАНИЯ К ФАЙЛУ-РЕЗУЛЬТАТУ:
- Формат: MP4 (кодек H.264), частота кадров — как в исходнике,
  разрешение — исходное (или 1920×1080, если исходник больше).
- Аудио удалить.
- Без надписей, титров, логотипов и водяных знаков.
- Яркость/цвета не менять.
- Формат кадра 16:9 (горизонтальный).
- Размер файла — не более 200 МБ.
- Имя файла: video-stend-30-45s.mp4
```

---

## 3. Как сдать результат (загрузить в тот же релиз)

Загрузить `video-stend-30-45s.mp4` в релиз `video-sources` через GitHub API.

Шаг 1 — узнать номер релиза (release id):

```
curl -H "Authorization: Bearer <ТОКЕН>" https://api.github.com/repos/DimaNikolaevi4/Konkurs/releases/tags/video-sources
```
(в ответе — поле `"id"`; токен выдаст Дмитрий в переписке)

Шаг 2 — залить файл:

```
curl -X POST -H "Authorization: Bearer <ТОКЕН>" -H "Content-Type: application/octet-stream" --data-binary "@video-stend-30-45s.mp4" "https://uploads.github.com/repos/DimaNikolaevi4/Konkurs/releases/<ID>/assets?name=video-stend-30-45s.mp4"
```

Убедиться в успехе: в ответе будет JSON с `"state": "uploaded"`
и ссылкой `browser_download_url`.

## 4. Отчёт по итогу (написать Дмитрию текстом)

- какой исходник использован (gotovyj / novyj_proekt_2) и с какой по какую секунду взят фрагмент;
- длительность и размер итогового файла;
- коротко: что происходит в кадре (это пойдёт в подпись на слайде);
- если оба исходника непригодны — почему и что нужно доснять заново.

## Критерии приёмки (проверит Дмитрий)

- [ ] В релизе появился файл `video-stend-30-45s.mp4` (доступен по browser_download_url)
- [ ] Длительность 30–45 с
- [ ] Звука нет, надписей нет, 16:9, MP4/H.264, ≤ 200 МБ
- [ ] В отчёте указаны границы фрагмента и что в кадре
- [ ] После приёмки файл скачивается локально, вставляется в слайд 6 презентации, релиз с исходниками удаляется
